# HeavyDuty для Amazfit Balance (Zepp OS 4.0) ⌚️🔥

Автономное приложение для силовых тренировок StrongLifts Plus & Heavy Duty на часах **Amazfit Balance (A2287)** под управлением **Zepp OS 4.0**.

---

## 🌟 Возможности приложения на часах

1. **Автономный трекинг без телефона**:
   * Выбор программы:
     * **Workout A**: Присед, Жим лежа, Тяга в наклоне, Пресс.
     * **Workout B**: Становая тяга, Армейский жим, Отжимания, Планка.
     * **Workout C**: Наклонный жим, Подтягивания, Разводка гантелей, Французский жим, Бицепс со штангой, Икры.
   * Отображение текущего веса и повторов.
   * Быстрые шаги изменения веса (`-2.5 кг`, `+2.5 кг`) и повторов (`-1`, `+1`) прямо с экрана часов.
2. **Пульс в реальном времени**:
   * Считывание данных с датчика BioTracker 5.0 часов Amazfit Balance во время подхода.
3. **Автоматический вибро-таймер отдыха**:
   * Отсчет времени отдыха между сетами (90 сек / 120 сек / 60 сек) с кнопками `+30 сек` и `Пропустить`.
   * **Тройная вибрация на запястье**, когда пора начинать следующий подход.
4. **Облачная синхронизация**:
   * После завершения тренировки Side Service через Bluetooth передает сессию в облако HeavyDuty.
   * Тренировка моментально появляется в веб-приложении на вашем телефоне или iPad.

## 🚀 Как установить на Amazfit Balance

### Способ 1: Установка через QR-код (Zeus CLI)

1. Убедитесь, что у вас установлен Node.js:
   ```bash
   cd zeppos-app
   npm install
   ```

2. Включите **Режим разработчика** в приложении **Zepp** на смартфоне:
   * Откройте приложение Zepp $\rightarrow$ вкладка **Профиль** $\rightarrow$ **Настройки** $\rightarrow$ **О приложении**.
   * Нажмите **7 раз подряд** на логотип Zepp (появится сообщение *«Режим разработчика включен»*).
   * Вернитесь в **Профиль** $\rightarrow$ появится новый пункт **Режим разработчика**.

3. Запустите сборку и создание QR-кода на компьютере:
   ```bash
   npx @zeppos/zeus-cli dev
   ```

4. В приложении Zepp на телефоне откройте **Профиль** $\rightarrow$ **Режим разработчика** $\rightarrow$ нажмите **«Сканировать»** (в правом верхнем углу) и наведите камеру на QR-код в терминале.
   * Приложение скомпилируется и установится прямо на ваши часы Amazfit Balance за пару секунд! 🎉

## ⚙️ Настройка ключа синхронизации (Sync Key)

1. В приложении Zepp на смартфоне перейдите в раздел установленных мини-программ $\rightarrow$ **HeavyDuty**.
2. Введите ваш персональный ключ синхронизации (например, `HD-7838-6732`).
3. Теперь любая тренировка, завершенная на часах, будет автоматически появляться в общем журнале HeavyDuty!
